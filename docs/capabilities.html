Lumitec Amazon

What you can ask Claude to do

Once the Lumitec Amazon MCPs are connected, Claude can operate your Amazon business directly — query orders, manage listings, analyse margins, tune ad campaigns, and more. Everything goes through official Amazon APIs; nothing is scraped.

Install it → GitHub
Two MCPs. One install. The plugin bundles two connected services — SP-API (everything in Seller Central) and Advertising API (all PPC and DSP). Both speak to Amazon on your behalf using credentials you provide once at setup.

📦Orders & Sales

Pull individual orders, search by date range or status, compute sales velocity, or generate bulk sales reports. Works across every marketplace you participate in.

Recent orders

  • Today's / this week's orders
  • Filter by status, marketplace, order value
  • Full order details + line items

Sales analysis

  • Units sold per SKU over any period
  • Sales velocity, seasonality trends
  • Pan-EU breakdown by country

Bulk reporting

  • 30-day order reports (cached locally for fast re-querying)
  • Returns, reimbursements
  • Financial settlement reports

Example prompts

Show me all orders from the last 7 days, grouped by marketplace.
How many units of SKU LUM-42 sold in the UK this month vs last month?
Which of my top-20 SKUs are trending down on sales in Germany?

⚡How it's fast

The skill uses a cache-first pattern for bulk data — it pulls a single 30-day orders report or a full listings dump, stores it on your machine, and queries it locally for ad-hoc questions. That means "how many sold?" queries return in a second, not a minute, and don't consume your Amazon API rate limit. Caching details →

🔒What Lumitec sees

Nothing at rest. Your Amazon credentials travel with each request as HTTP headers and are discarded from memory after each call. Order data, listings, financial events — none of it is stored on Lumitec's side. The cache lives only on your machine. You remain the registered Amazon developer and sole custodian of your data.
